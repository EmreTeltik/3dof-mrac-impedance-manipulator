# Modeling and simulation area

MATLAB/Simulink is the planned environment for the dynamic model, reference model, baseline controller, MRAC development, and experimental analysis. No `.slx` model or completed controller is included in this initial repository.

For each future model add a parameter script, solver/sample-time settings, exact MATLAB/toolbox versions, reference trajectory, payload scenario, baseline configuration and a reproducible run procedure. A model screenshot should link to its executable model or script and be labelled simulation.
